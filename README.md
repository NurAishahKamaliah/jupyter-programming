# jupyter-programming
Supply chain analytics project from EDA to insights. DataCo Global dataset.

# Course
Programming for Data Analytics | Semester 4 Year 2

# Dataset Source

This dataset is provided by DataCo Global for analysis of sales, provisioning, production, and commercial distribution using Machine Learning algorithms and R software.

- **Original contributor:** Fabian Constante (Master student, Instituto Politecnico de Leiria)
- **Shared by:** Shashwat Tiwari on Kaggle
- **Files:** 3 CSV files (structured data, unstructured data, data description)
- **For this project:** Structured data only

## What This Project Does

This analysis is divided into 4 phases:

| Phase | Description |
|-------|-------------|
| 1. Exploratory Data Analysis (EDA) | Understanding data distribution, identifying patterns, and detecting anomalies |
| 2. Preprocessing & Feature Engineering | Cleaning data, handling missing values, creating new features |
| 3. Analysis & Visualization | Generating insights through charts, graphs, and statistical summaries |
| 4. Modelling & Insights | Applying ML algorithms to predict and extract business recommendations |

# Technologies Used

- **Language:** Python 
- **Libraries:** pandas, numpy, matplotlib, seaborn, scikit-learn
- **Tools:** Jupyter Notebook

# How to Run

1. Clone this repository
2. Download the dataset from [https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis?select=DataCoSupplyChainDataset.csv]
3. Open `DataCo_Analysis.ipynb`
4. Run cells sequentially
